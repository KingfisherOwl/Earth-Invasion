# Earth Invasion

地理を楽しく学べる、地球侵略をテーマにしたクイズゲームです。

## ゲーム概要

プレイヤーは地球の各地域を調査し、地理に関するクイズに挑戦します。

クイズで獲得した「地球の神秘」を使用すると、世界遺産を解放できます。

地域および世界遺産クイズのコンプリートを目指します。

## 遊び方

1. 調査したい地域を選択します。
2. 地理に関する5問のクイズに挑戦します。
3. 正解数に応じて「地球の神秘」を獲得します。
4. 世界遺産を解放し、調査を進めます。

## 動作環境

Webブラウザでプレイできます。PCでのプレイを推奨します。ボタンが小さいためスマホに対応していません。

データは端末ごとに保存されます。

## クレジット

本ゲームの世界遺産背景画像は、OpenAIのChatGPTを使用して作成しています。

画像は実際の写真ではなく、世界遺産の景観を表現したイメージです。実際の建築物や地形などと異なる場合があります。

また、本ゲームの一部の問題は、OpenAIのChatGPTを使用して作成しています。
